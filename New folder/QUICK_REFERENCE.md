# Bible Study Assistant - Quick Reference Card

## 🚀 Installation (5 minutes)

### 1. Get API Key
→ https://aistudio.google.com/apikey → Create API Key → Copy key

### 2. Load Extension
→ `chrome://extensions/` → Developer Mode ON → Load unpacked → Select folder

### 3. Configure
→ Click extension icon → ⚙️ Settings → Paste API key → Save

---

## 📖 How to Use

### Step 1: Open biblegateway.com
Select a Bible passage you want to study

### Step 2: Click Extension Icon
The popup opens with your study tools

### Step 3: Choose Action
**Option A: Quick Actions**
- 📌 **Summarize** - Get overview
- 🔑 **Key Points** - Find themes
- 🔗 **Cross Reference** - Find related verses
- 📚 **Context** - Learn background

**Option B: Custom Question**
- Type your question
- Click "Ask Assistant"
- Get AI response in 2-5 seconds

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| No response | Check API key in settings |
| Invalid API key | Get new key at aistudio.google.com/apikey |
| Can't extract content | Make sure you're on biblegateway.com |
| Extension won't load | Reload in chrome://extensions/ |
| Settings won't save | Try pasting key again |

### Emergency Checklist

**Extension won't load?**
1. Make sure manifest.json exists ✓
2. Make sure Developer mode is ON ✓
3. Try "Load unpacked" again ✓
4. Reload in chrome://extensions/ ✓

**API key rejected?**
1. Go to aistudio.google.com/apikey ✓
2. Delete old key ✓
3. Create new key ✓
4. Copy carefully ✓
5. Paste in settings ✓

**Getting no responses?**
1. Check internet connection ✓
2. Check API key in settings ✓
3. Make sure you're on biblegateway.com ✓
4. Try test.html instead ✓
5. Check console (F12) for errors ✓

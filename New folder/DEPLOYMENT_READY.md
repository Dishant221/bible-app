## 📱 Installation Quick Reference

**For Users (5-10 minutes):**

1. Get API Key
   ```
   → https://aistudio.google.com/apikey
   → Create API Key
   → Copy
   ```

2. Load Extension
   ```
   → chrome://extensions/
   → Developer Mode ON
   → Load unpacked → Select folder
   ```

3. Configure
   ```
   → Click icon → ⚙️ → Paste key → Save
   ```

4. Test
   ```
   → Open test.html or biblegateway.com
   → Click icon → Click "Summarize"
   → Verify response appears
   ```

**Time: ~10 minutes**

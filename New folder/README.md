# Bible Study Assistant - Chrome Extension

A powerful AI-powered Bible study companion for Chrome that helps you study, understand, and explore Bible passages on **biblegateway.com** using Google Gemini.

## Features

✨ **Smart Bible Study Tools:**
- **Summarize** - Get concise summaries of Bible passages
- **Key Points** - Extract main themes and theological insights
- **Cross References** - Discover related Bible passages and connections
- **Context & Meaning** - Understand historical, cultural, and theological context

🎯 **Quick Actions:**
- One-click study options for faster learning
- Custom question support for deep exploration
- Instant AI-powered responses

🔐 **Privacy & Security:**
- Your API key stored securely in local storage
- Content treated as untrusted data (protection against prompt injection)
- No data collection or tracking

## Installation

### 1. Get a Google Gemini API Key

1. Visit [Google AI Studio](https://aistudio.google.com/apikey)
2. Click "Create API Key"
3. Copy your API key

### 2. Load the Extension in Chrome

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top-right)
3. Click **Load unpacked**
4. Navigate to the extension folder and select it
5. The extension should now appear in your extensions list

### 3. Configure Your API Key

1. Click the extension icon in your Chrome toolbar
2. Click the **⚙️ Settings** button
3. Paste your Gemini API key
4. Click **Save API Key**

## How to Use

1. **Navigate to biblegateway.com** and select a Bible passage
2. **Click the extension icon** to open the Page Assistant
3. **Choose an action:**
   - Use quick action buttons (Summarize, Key Points, Cross Reference, Context)
   - Or type a custom question in the text area
4. **Click "Ask Assistant"** and wait for the response
5. Responses appear in a formatted panel with full Markdown support

## Troubleshooting

### Extension not loading?
- Make sure Developer mode is enabled in `chrome://extensions/`
- Try refreshing the extension (reload button next to it)

### API key errors?
- Verify the key is valid at [Google AI Studio](https://aistudio.google.com/apikey)
- Check that you have remaining API quota
- Try re-entering the key in settings

### Page content not extracting?
- Make sure you're on **biblegateway.com**
- Try selecting a different Bible passage
- Refresh the page and try again

### Poor response quality?
- Make sure the passage is fully loaded on the page
- Try rephrasing your question
- Use more specific queries for better results

## Tips for Best Results

1. **Use specific passages** - Full chapters or books will give better context
2. **Ask clear questions** - Be specific about what you want to know
3. **Combine methods** - Use quick actions then ask follow-up questions
4. **Check multiple versions** - Try different Bible versions on biblegateway.com for different contexts

# Bible Study Assistant - User Manual

Welcome to your AI-powered Bible study companion! This guide shows you how to use the extension effectively.

---

## 🎯 Getting Started in 3 Steps

### 1️⃣ Installation
- Install the extension in Chrome (`chrome://extensions/` → Load unpacked)
- See `INSTALLATION_GUIDE.md` for detailed steps

### 2️⃣ Configure API
- Click extension icon → ⚙️ Settings
- Paste your Google Gemini API key
- Click "Save API Key"

### 3️⃣ Start Studying
- Go to biblegateway.com and select a passage
- Click the extension icon
- Use quick actions or ask questions

---

## 🎮 How to Use

### Quick Actions

The extension provides 4 quick actions to help you study:

#### 📌 **Summarize**
Provides a concise overview of the passage.

**Best for:**
- Quick understanding of what a passage says
- Getting the main idea before deep study
- Sharing with others

**Example:**
> "For God so loved the world..." → "This verse expresses God's love and the promise of eternal life through Jesus..."

---

#### 🔑 **Key Points**
Extracts the main themes, theological concepts, and important ideas.

**Best for:**
- Understanding what the passage teaches
- Identifying central messages
- Sermon prep or teaching

**Example:**
> Returns: Divine love, sacrifice, faith, eternal life

---

#### 🔗 **Cross Reference**
Finds related Bible passages and connections to other scriptures.

**Best for:**
- Understanding how passages connect
- Finding related teachings in Scripture
- Building biblical understanding

**Example:**
> Related passages: John 1:1, Romans 5:8, 1 John 4:9-10

---

#### 📚 **Context & Meaning**
Provides historical, cultural, and theological context.

**Best for:**
- Understanding the background of passages
- Learning about ancient customs
- Deeper theological exploration

**Example:**
> Historical context about 1st century Judaism, Jesus's audience, theological significance...

---

### Custom Questions

Ask any question about the displayed passage:

**Examples:**

📖 **Literal Understanding**
- "What does this verse literally say?"
- "What is the main action in this passage?"

🤔 **Interpretation**
- "What does this passage mean?"
- "How does this apply to believers today?"

✝️ **Theological**
- "What does this teach about God?"
- "How does this relate to salvation?"

💡 **Practical**
- "How can I apply this in my life?"
- "What is God's message here?"

🔍 **Comparative**
- "How is this different from [other passage]?"
- "What is emphasized in this version vs. others?"

## 🛠️ Features Explained

### API Key Settings
- **Secure:** Stored only in your browser, never sent to our servers
- **Private:** Only used to communicate with Google Gemini
- **Reversible:** Delete anytime and save a new key

### Response Display
- **Formatted:** Responses use markdown formatting for readability
- **Scrollable:** Long responses scroll within the popup
- **Clear:** Responses are structured with headings and lists

### Error Handling
- **Helpful messages:** Clear explanations when something goes wrong
- **Auto-recovery:** Try again or check your settings
- **Support:** Consult the troubleshooting guide

## 💡 Tips for Better Results

### ✨ Tip 1: Use Shorter Passages
**Better:** Single verses or short passages
**Worse:** Entire books

Why? Shorter content = faster, better-focused responses

### ✨ Tip 2: Be Specific with Questions
**Better:** "What does 'born again' mean in John 3:3?"
**Worse:** "What does this mean?"

Why? Specific questions get more accurate answers

### ✨ Tip 3: Follow Up Questions
**Pattern:**
1. Use "Summarize" to understand the passage
2. Ask specific follow-up questions
3. Explore deeper with custom questions

Why? Builds comprehensive understanding

### ✨ Tip 4: Try Different Actions
**Order:**
1. Read the passage yourself
2. Click "Summarize" for overview
3. Click "Key Points" for themes
4. Click "Cross Reference" for connections
5. Ask custom questions

Why? Each action provides different insights

### ✨ Tip 5: Compare Bible Versions
**Try:**
1. Read passage in one version
2. Click "Summarize"
3. Switch to another version (on biblegateway.com)
4. Compare responses

Why? Different translations highlight different nuances

## ❓ Common Questions

**Q: How long do responses take?**
A: Usually 2-5 seconds. Longer passages may take up to 10 seconds.

**Q: Is my data private?**
A: Yes. Your passages are only sent to Google Gemini for analysis. Your API key is stored only in your browser.

**Q: Can I use this offline?**
A: No, the extension requires internet to communicate with Google Gemini.

**Q: How many questions can I ask?**
A: Unlimited, but you have a monthly API quota. See your usage at https://aistudio.google.com/apikey

**Q: What Bible versions are supported?**
A: Any version available on biblegateway.com.

**Q: Can I save responses?**
A: You can copy and paste responses to your notes, but the extension doesn't have a built-in save feature yet.

**Q: What languages are supported?**
A: The extension works on biblegateway.com in any language.

**Q: Can I use other Bible websites?**
A: Currently only biblegateway.com. Future versions may support other sites.

**Q: How much does it cost?**
A: Free! Google Gemini API has a generous free tier. Check your usage at Google AI Studio.

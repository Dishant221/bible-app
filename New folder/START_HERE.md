## ✅ Checklist: Get Running in 5 Steps

### Step 1: Get Google Gemini API Key (2 min)
```
1. Go to: https://aistudio.google.com/apikey
2. Click "Create API Key"
3. Copy the key (looks like AIzaSy...)
```

### Step 2: Load Extension in Chrome (2 min)
```
1. Open: chrome://extensions/
2. Turn ON "Developer mode" (top-right)
3. Click "Load unpacked"
4. Select biblexistance folder
5. Check that it loads with no errors
```

### Step 3: Configure API Key (1 min)
```
1. Click extension icon (📖)
2. Click ⚙️ Settings
3. Paste API key
4. Click "Save API Key"
5. See "API key saved successfully!"
```

### Step 4: Quick Test (2 min)
```
1. Open: test.html file in browser (or go to biblegateway.com)
2. Click extension icon
3. Click "Summarize" button
4. Wait 3-5 seconds
5. See AI response about the Bible verse
```

### Step 5: Start Using! (Ongoing)
```
1. Go to biblegateway.com
2. Select any Bible passage
3. Click extension icon
4. Use quick actions or ask questions
5. Get AI-powered insights
```

**Total time: ~10 minutes from start to using it** ⏱️
